# Changelog

## 1.1.0

- Predicted-bug reports: every suite now lists the bugs it will expose, with code evidence, before you run it
- Syntax-validated output for JS/TS, with an automatic repair round when generated code doesn't parse
- Multi-file context (`related_files`) for correct imports and cross-file understanding
- Four new frameworks: Go, PHPUnit, RSpec, cargo test (8 total)

## 1.0.0

- Initial hosted release: adversarial test-suite generation from a 153-pattern edge-case checklist
- Frameworks: Jest, Vitest, node:test, pytest
- Coverage reports, auto-use instructions for agents, free tier (5 suites/month)
